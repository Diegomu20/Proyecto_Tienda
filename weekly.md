# Seguimiento Semanal - Sprint 3

## Semana de trabajo

Durante esta semana se trabajó en la implementación del motor de plantillas EJS dentro de la aplicación Node.js con Express.

## Actividades realizadas

- Instalación y configuración de EJS en el servidor.
- Reorganización del proyecto en carpetas (views, partials y public).
- Conversión de archivos HTML a formato .ejs.
- Implementación de componentes reutilizables (header y footer).
- Creación de rutas en Express usando render.
- Desarrollo del formulario para crear productos.
- Desarrollo del formulario para editar productos.
- Pruebas de funcionamiento de las vistas y rutas.

## Avances logrados

- Se logró integrar correctamente EJS en la aplicación.
- Las vistas ahora son dinámicas y reutilizan componentes.
- Se cuenta con formularios funcionales para creación y edición de productos.

## Dificultades

- Problemas iniciales con la configuración de rutas.
- Adaptación del código JavaScript al uso de EJS.
- Errores al cargar vistas por mala ubicación de carpetas.

## Próximos pasos

- Mejorar la lógica de almacenamiento de productos.
- Optimizar el código del frontend.
- Realizar pruebas adicionales antes de la entrega final.
