# Retrospectiva — Sprint 7: Validaciones (Back + Front)

## ⭐ Estrella de Mar

### 1. Comenzar a hacer
- Validar formularios en el front-end desde el primer sprint para mejor UX.
- Usar librerías de validación como `express-validator` desde el inicio del proyecto.

### 2. Hacer más
- Feedback visual inmediato al usuario (mensajes de error campo por campo).
- Revisión de código en equipo antes de hacer push.

### 3. Continuar haciendo
- Separar la lógica de validación en un middleware independiente (`validators.js`).
- Mantener consistencia entre las validaciones de back-end y front-end.

### 4. Hacer menos
- Depender únicamente de los atributos `required` de HTML (fácilmente desactivables).
- Mezclar la lógica de negocio con la validación en el mismo bloque de código.

### 5. Dejar de hacer
- Confiar solo en las validaciones del front-end.
- Dejar campos sin restricciones en la base de datos.
