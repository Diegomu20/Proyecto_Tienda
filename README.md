## Tablero de trabajo por Sprints
El desarrollo del proyecto se organizará utilizando la metodología **Scrum**, dividiendo las actividades en sprints.

### Sprint 1 – Planeación
- Definición del alcance del proyecto
- Identificación de requisitos
- Selección de tecnologías
- Creación del repositorio en GitHub
- Definición de la estructura del proyecto

### Sprint 2 – Desarrollo inicial
- Creación del frontend base
- Diseño inicial de la interfaz
- Configuración del servidor con Node.js y Express

### Sprint 3 – Funcionalidades principales
- Gestión de productos
- Gestión de categorías
- Conexión con la base de datos MySQL
- Validaciones básicas

### Sprint 4 – Pruebas y ajustes
- Pruebas funcionales
- Corrección de errores
- Ajustes finales y documentación
